"""# TP Flutter Corrigé

## Travail demandé
Reproduire et améliorer les dernières applications dont les codes sont exposés dans le support Introduction à Flutter.

## Applications réalisées
1. Application simple avec StatelessWidget
2. Compteur avec StatefulWidget et setState
3. Liste de produits avec panier
4. Formulaire de connexion avec validation

## Exécution avec Android Studio
1. Installer Flutter SDK.
2. Installer Android Studio.
3. Ouvrir le dossier `flutter_tp_corrige`.
4. Lancer dans Terminal :

```bash
flutter pub get
flutter run
```

## Exécution avec téléphone Android
1. Activer Options développeur.
2. Activer Débogage USB.
3. Connecter le téléphone au PC.
4. Lancer :

```bash
flutter devices
flutter run
```

## Fichier principal
Le code est dans :

```text
lib/main.dart
```
